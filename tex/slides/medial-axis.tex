\begin{frame}{The Medial Axis}
	\begin{itemize}
		\item The medial axis is similar to a Voronoi diagram but for an infinite set of points
		\item The medial axis is the set of all points in the plane that are nearest to more than one point of the smooth curve.
		\item This definition allows the medial axis to serve as a sort of midline throughout a shape
	\end{itemize}
\end{frame}
