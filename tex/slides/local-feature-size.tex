\begin{frame}{Local Feature Size}
	\begin{itemize}
		\item At a point $p$ on a smooth curve, we can define the local feature size, $LFS(p)$ as the distance to the closest point of the medial axis
		\item As the name suggests, the local feature size gives an idea of how big the features of a shape are at any given point
		\item When a curve is more detailed, LFS is small, and when a curve is very flat it is large
	\end{itemize}
\end{frame}
