\begin{abstract}
	The crust is an algorithm to reconstruct a discrete set of points sampled from a smooth curve presented by \citet{crust}.
	This algorithm depends on a few foundational discrete geometric tools that are applied across many fields including Voronoi Diagrams and Delaunay Triangulations.
	The theory behind these tools and the crust is introduced, and efficient implementations are provided.
\end{abstract}
